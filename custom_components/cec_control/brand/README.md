# Brand assets

`icon.png` and `icon@2x.png` are the Material Design Icons glyph `hdmi-port`,
rendered in black on a transparent background at 256×256 and 512×512.

Material Design Icons is licensed Apache-2.0. See
<https://github.com/Templarian/MaterialDesign>.

HACS looks for `icon.png` here and only falls back to the Home Assistant brands
repository when it is missing. This integration is not in that repository and is
not going to be, so the assets live with the code.
